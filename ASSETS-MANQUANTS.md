# Assets manquants

Tous les assets critiques utilisés dans cette V1 ont été récupérés depuis `https://luxos.co.za/` et stockés dans `src/assets/images` avec des noms sémantiques en kebab-case.

Les variantes WordPress responsives dupliquées (`-300x`, `-768x`, `-1024x`, etc.) n'ont pas été recopiées quand une version originale ou haute définition équivalente était disponible.
